# Independent repository that keeps the Apache notice

Omanotes began from omatodolist, Copyright (c) 2026 Cailan Sacks, under the Apache License 2.0. It lives in its own repository with its own history and is not a GitHub fork. `LICENSE` is the unchanged Apache 2.0 text, and `NOTICE` keeps the original copyright line and states that Omanotes includes and modifies omatodolist, because section 4 of the license requires keeping those notices in derivative works.

## Consequences

- `NOTICE` stays, even though the project no longer tracks the original.
- Text inherited from omatodolist (README, screenshot, descriptions) has to be rewritten for Omanotes rather than kept.
